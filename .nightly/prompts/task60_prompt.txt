## 1. Purpose and background

The approver proofreads the magazine 『國際寫眞新聞』 in the confirmation viewer.
"この枠だけOCR" (custom_gui/region_ocr.py, region_ocr_text) crops a frame and
runs the upstream NDLOCR (src/ocr.py) on the crop. NDLOCR first DETECTS text
lines, then reads each line; a line crop that is taller than wide is rotated
90 degrees counter-clockwise and read as vertical text (src/parseq.py,
PARSEQ.preprocess: `if h>w: img=cv2.rotate(img,cv2.ROTATE_90_COUNTERCLOCKWISE)`).

Problem found on 2026-10-08 (141号 p41, Region 8). An article of 24 short
vertical columns (8 characters each, characters aligned in a grid) is detected
as 7 HORIZONTAL lines across the columns, so the text is nonsense. Rotating the
crop by 90 degrees either way did not help (the detector found the same rows).

The commander measured a method that works (one frame, one run):
cut the frame into columns by the vertical white gaps, WITHOUT line detection,
and give each column crop directly to PARSEQ (which rotates it because it is
taller than wide). All 24 body columns and the 4 heading columns were read as
correct vertical text, right to left, in 16.9 s on CPU.

You implement exactly that method as a pure, testable module.

## 2. Contract

### DoD-1 -- new file custom_gui/vertical_ocr.py

Module constants (names and values exactly):

    PHOTO_ROW_RATIO = 0.35   # a crop row with a larger ink ratio is "photo"
    MIN_RUN = 5              # ink runs narrower than this (px) are ignored
    MARGIN = 3               # px added around each column crop

Imports allowed: os, sys, threading, numpy, cv2, yaml (safe_load),
custom_gui.mark_detector (load_image), custom_gui.region_ocr (crop_region,
REGION_OCR_PAD). PARSEQ is imported lazily inside get_recognizer (below).

Functions (names and signatures exactly):

1. `def ink_mask(image_bgr) -> numpy.ndarray`
   Grayscale (cv2.COLOR_BGR2GRAY), then
   cv2.threshold(gray, 0, 1, cv2.THRESH_BINARY_INV + cv2.THRESH_OTSU).
   Returns a uint8 array of 0/1 with 1 = ink. Same height/width as the input.

2. `def text_band(mask) -> tuple[int, int]`
   ratio[y] = mask[y].mean(). A row is "text-like" when ratio[y] <=
   PHOTO_ROW_RATIO. Return (y1, y2) = the LONGEST run of consecutive
   text-like rows (y2 exclusive). On a tie, the FIRST (topmost) run.
   If there is no text-like row, return (0, 0).

3. `def split_columns(mask) -> list[tuple[int, int]]`
   H = mask.shape[0]. on[x] = mask[:, x].sum() > max(2, H * 0.01).
   runs = maximal runs of consecutive on[x], as (x1, x2) with x2 exclusive;
   drop runs with x2 - x1 < MIN_RUN.
   If no run is left, return [].
   widths = the run widths (float). q = numpy.percentile(widths, 25).
   pitch = numpy.median(widths[widths <= 1.5 * q]).
   Every run is split into n = max(1, int(round(width / pitch))) equal parts:
   part i = (int(round(x1 + i*step)), int(round(x1 + (i+1)*step))),
   step = width / n. Return all parts, LEFT to RIGHT.

4. `def get_recognizer()`
   Lazily builds ONE PARSEQ and caches it in a module variable (guarded by a
   threading.Lock). It loads, exactly as src/ocr.py does by default:
     model   = <repo>/src/model/parseq-ndl-24x768-100-tiny-153epoch-tegaki3-r8data-202604.onnx
     classes = <repo>/src/config/NDLmoji.yaml
     charlist = list(safe_load(f)["model"]["charset_train"])  (utf-8)
     PARSEQ(model_path=model, charlist=charlist, device="cpu")
   <repo> = the parent of the custom_gui directory. To import PARSEQ, put
   <repo>/src on sys.path (only if it is not there) and `from parseq import
   PARSEQ`. Do NOT modify anything under src/.

5. `def vertical_ocr_text(image_path: str, bbox, pad: int = REGION_OCR_PAD,
                          recognizer=None) -> str`
   a. crop = crop_region(mark_detector.load_image(image_path), bbox, pad)
   b. mask = ink_mask(crop); (y1, y2) = text_band(mask);
      if y2 <= y1: return "".
      band = mask[y1:y2]; img = crop[y1:y2]
   c. cols = split_columns(band)
   d. For each (x1, x2) in cols from RIGHT to LEFT:
        ys = rows of band[:, x1:x2] that contain ink; skip if none.
        a = max(0, ys[0] - MARGIN); b = min(band height, ys[-1] + 1 + MARGIN)
        c = img[a:b, max(0, x1 - MARGIN):min(band width, x2 + MARGIN)]
        skip c if c.shape[0] <= c.shape[1]   (not taller than wide)
        t = rec.read(c)   where rec = recognizer or get_recognizer()
        keep t if it is non-empty and not only whitespace
   e. return "\n".join(kept texts)   ("" if none)
   get_recognizer() must NOT be called when `recognizer` is given.
   Exceptions from load_image or rec.read propagate unchanged.

Nothing else. Do not change region_ocr.py, ocr_bridge.py, app.py or src/.
