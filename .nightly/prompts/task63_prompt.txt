## 1. Purpose and background

custom_gui/vertical_ocr.py (Task 60, on master) reads a frame as vertical
text: ink_mask -> text_band (drop rows whose ink ratio > PHOTO_ROW_RATIO,
keep the longest remaining run of rows) -> split_columns (runs of x where
the column profile is non-zero; a run wider than the "pitch" is cut into
EQUAL parts) -> each column, right to left, to PARSEQ.

It failed on 141号 p42 (2026-10-08, measured by the commander, one frame):
  A. A photo strip at the LEFT side of the frame raised every row's ink
     ratio above 0.35, so text_band kept only the bottom quarter of the
     frame and each column was read only partly.
  B. The 8 body columns are about 950 px tall; because of a slight skew and
     punctuation, the white gaps between them are never fully empty, so the
     8 columns were one run 233 px wide.
The commander tried three changes in a scratch script and on p42 the whole
article was then read correctly, while 141号 p41 stayed the same quality:
  1. remove photos per 48x48 tile (ink ratio > 0.5) before anything else;
  2. measure the column width (pitch) from the autocorrelation of the column
     profile inside the WIDEST run, taking the SHORTEST strong period;
  3. cut a merged run at the valleys (minima) of the smoothed profile near
     the ideal cut positions, instead of equal parts.
You implement exactly these, as below.

## 2. Contract (custom_gui/vertical_ocr.py)

### DoD-1 -- new constants (names and values exactly)

    TILE = 48              # px, side of a photo tile
    TILE_RATIO = 0.5       # a tile with a larger ink ratio is "photo"
    PITCH_MIN = 15         # px, shortest column width searched
    PITCH_MAX = 80         # px, longest column width searched (exclusive)
    PEAK_RATIO = 0.7       # a peak at least this fraction of the top peak is "strong"
    SMOOTH = 5             # px, moving-average window for the column profile
    MIN_WIDTH_RATIO = 0.4  # runs narrower than pitch * this are dropped

### DoD-2 -- new function

    def remove_photo_tiles(mask) -> numpy.ndarray:
        """Return a COPY of mask where every TILE x TILE tile (from the top
        left; the last row/column of tiles may be smaller) whose mean is
        > TILE_RATIO is set to 0. The input is not modified."""

### DoD-3 -- new function

    def estimate_pitch(profile, runs) -> int:
        """profile: 1-D float array (the smoothed column profile).
        runs: list of (x1, x2), x2 exclusive, non-empty.
        1. (s, e) = the widest run (first one on a tie).
        2. If e - s < 40: return int(numpy.median([x2 - x1 for x1, x2 in runs])).
        3. v = profile[s:e] - profile[s:e].mean()
           lags = range(PITCH_MIN, min(PITCH_MAX, len(v) // 2))
           If lags is empty: return e - s.
           ac[lag] = dot(v[:-lag], v[lag:]) / (len(v) - lag)
           top = max(ac). If top <= 0: return e - s   (no periodicity: do not split)
        4. Return the SMALLEST lag that is a local peak
           (ac[lag] >= ac[lag-1] and ac[lag] >= ac[lag+1], both neighbours
           inside lags) with ac[lag] >= PEAK_RATIO * top.
           If there is none, return the lag of top (smallest on a tie)."""

### DoD-4 -- split_columns(mask) is rewritten (same signature, same return:
list of (x1, x2), left to right)

    H = mask.shape[0]; if H == 0: return []
    prof = mask.sum(axis=0).astype(float)
    sm = numpy.convolve(prof, numpy.ones(SMOOTH) / SMOOTH, mode="same")
    runs = maximal runs of prof > max(2, H * 0.01), as (x1, x2) x2 exclusive,
           keeping only runs with x2 - x1 >= MIN_RUN
    if not runs: return []
    p = estimate_pitch(sm, runs)
    for each run (s, e) left to right:
        w = e - s
        if w < MIN_WIDTH_RATIO * p: drop it
        n = max(1, int(round(w / p)))
        cuts = [s]; prev = s
        for i in 1 .. n-1:
            ideal = s + i * w / n
            lo = max(int(ideal - p / 3), prev + 1)
            hi = min(int(ideal + p / 3), e - 1)
            if hi > lo:
                c = the x in [lo, hi] with the smallest sm[x]; on a tie, the
                    one closest to ideal; on a further tie, the smaller x
            else:
                c = int(ideal)
            cuts.append(c); prev = c
        cuts.append(e)
        columns += consecutive pairs of cuts
    return columns
