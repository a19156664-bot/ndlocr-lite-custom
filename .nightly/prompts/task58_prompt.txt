================================================================================
Task 58: A batch tool that runs "mark reading + region OCR" on pages nobody
         has touched yet, before the human inspection
================================================================================

This order is Task 58 in .nightly/ROADMAP.md (AGENTS.md section 8.11).

## 1. Purpose and background

The approver inspects issue 141 in the check viewer (launch_viewer.py). On
each page they press "マーク読取" (custom_gui/app.py _on_marks_to_rects_click:
it adds one box per lime marker found by custom_gui.mark_detector.detect_marks)
and then, for each of those boxes, "この枠だけOCR" (app.py start_region_ocr:
custom_gui.region_ocr.region_ocr_text crops the box from the page PNG and
OCRs only the crop; the result is stored in the page's edits under the
box id). The region OCR reads much better than the full-page OCR, but one box
takes about 2 minutes (measured 104-150 s for 3 boxes on 2026-10-07).

The approver decided (2026-10-07) to do this in advance with a batch tool
that runs at night while the viewer is closed. It must never touch a page the
human has already worked on, and must not run while the viewer is open
(the viewer keeps every page's state in memory and would overwrite the
batch's files later).

## 2. Contract

### DoD-1 -- new module custom_gui/batch_region_ocr.py

Command line (argparse):

    python -m custom_gui.batch_region_ocr --issue 141
        [--pages 18-52]          # 1-based, inclusive; "N" or "N-M"; default all
        [--base <dir>]           # repository root; default: the parent folder
                                 #   of the custom_gui package
        [--viewer-port 8555]     # default 8555

Paths, all under --base, exactly as launch_viewer.py builds them:

    PDF       work/国際寫眞新聞_{issue}号.pdf
    RAW JSON  work/output/01_raw_ocr/国際寫眞新聞_{issue}号.json
    PNG dir   work/cache_images/{issue}号/
    PNG name  国際寫眞新聞_{issue}号_p{n:04d}.png   (n = 1-based page number)

Expose `def main(argv=None) -> int` and call it under
`if __name__ == "__main__": sys.exit(main())`.

Steps of main, in this order:

1. Viewer guard. Try to open a TCP connection to 127.0.0.1:<viewer-port>
   (socket.create_connection with timeout 1.0). If it connects, print
   "ビューアが開いています（127.0.0.1:<port>）。閉じてから走らせてください。"
   and return 2 WITHOUT writing anything. Put this check in a function
   `viewer_is_open(port: int) -> bool`.
2. If the PDF or the RAW JSON does not exist: print which, return 1.
3. Page count = len(json["contents"]) of the RAW JSON. --pages outside
   1..count: print and return 1.
4. For each selected page n (1-based; page_index = n - 1), in ascending order:
   a. If os.path.exists(work_state.work_path_for(PDF, page_index)): print
      "p{n}: 保存あり → 飛ばす" and continue. (Never read or rewrite it.)
   b. png = PNG dir / PNG name. Call
      pdf_loader.ensure_page_rendered(png, PDF, page_index).
   c. regions = mark_detector.detect_marks(mark_detector.load_image(png),
      color="lime"). (Section 8.3: issues 141-145 use lime only; no page mark,
      no orange.)
   d. If regions is empty: print "p{n}: マーク 0 → 書かない" and continue
      (no file is written; the viewer will make its Region 1 as today).
   e. Build the boxes with a real custom_gui.selection.SelectionContainer:
      - first, Region 1 exactly as launch_viewer.py does when a page has no
        saved state: from that page's RAW JSON lines (normalized the same
        way as launch_viewer.normalize_page_ocr), bbox =
        (max(0.0, min_x - 15.0), max(0.0, min_y - 15.0), max_x + 15.0,
        max_y + 15.0) over all lines' x1/x2/y1/y2. If the page has no lines,
        do not add Region 1.
      - then container.add(region.bbox) for each region, in the order
        detect_marks returned them.
      (So with lines, the ids are "1" for Region 1 and "2".."k+1" for marks.)
   f. For each MARK box (not Region 1), in id order:
      text = region_ocr.region_ocr_text(png, box.bbox)
      If text is non-empty: edits[box.rect_id] = text. If it is "" (no
      text found): no entry. If it raises: print the error for that box,
      leave no entry, and continue with the next box.
      Print one line per box as it finishes:
      "p{n} 枠{rect_id}: {seconds:.0f} 秒 {lines} 行" (flush=True).
   g. Just before saving, check os.path.exists(work_path_for(PDF,
      page_index)) AGAIN. If it now exists (someone saved meanwhile): print
      "p{n}: 途中で保存された → 書かない" and continue without writing.
   h. work_state.save_work_state(PDF, container.get_all(), edits, None,
      page_index=page_index).
5. Print a summary line: pages written / skipped (saved) / no marks /
   boxes OCR'd / boxes with no text / errors. Return 0.

Rules:
- Call the dependencies through their modules (mark_detector.detect_marks,
  region_ocr.region_ocr_text, pdf_loader.ensure_page_rendered,
  work_state.save_work_state), i.e. `from custom_gui import region_ocr` and
  `region_ocr.region_ocr_text(...)`, so a test can replace the attribute on
  the module.
- region_ocr_text runs src/ocr.py with a relative path, so the tool must be
  started from the repository root. At the start of main (after the viewer
  guard), if os.path.exists("src/ocr.py") is False, print that and return 3.
- Do not import flet. Do not import launch_viewer (it runs at import time).
- Do not change any other file.
