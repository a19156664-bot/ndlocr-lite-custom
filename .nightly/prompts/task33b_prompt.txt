2.2 `self.ocr_results` IS A LIST OF DICTS, NOT TUPLES.

    Task 33 wrote:

        for r_id, b_text, c_text in self.ocr_results:      # WRONG
            if str(r_id) == rect.rect_id:
                extracted_text = c_text

    There is no region id in `ocr_results` and the entries are not 3-tuples.
    Each entry is exactly:

        {"text": str,
         "bbox": (x1, y1, x2, y2),
         "confidence": float,
         "is_vertical": bool,
         "source_image": str}

    A rectangle's text is derived by FILTERING the lines geometrically. The
    correct code already exists in `_update_selections_ui` - copy this shape:

        x1, y1, x2, y2 = rect.bbox
        filtered_lines = filter_lines_by_region((x1, y1, x2, y2), self.ocr_results)
        extracted_text = assemble_text(filtered_lines)
        has_edit = rect.rect_id in self.edits
        display_text = self.edits[rect.rect_id] if has_edit else extracted_text

    `filter_lines_by_region` and `assemble_text` are already imported in app.py.

2.3 DO NOT ADD THE PAN OFFSET TWICE.

    Task 33 set `inline_editor_layer.left = self.offset_x` AND then also did
    `dx1 += self.offset_x` for the child. That is the exact bug Task 30d had to
    fix for the drag preview.

    Since Task 30c, a layer carries the offset and its CHILDREN are positioned
    with zero offset:

        dx1, dy1 = original_to_display(x1, y1, self.zoom_scale, 0.0, 0.0)

    Set the layer's `.left` / `.top` to the offset. Position children with
    0.0, 0.0. Never both.

3. THREE MORE TRAPS THE COMMANDER FOUND
================================================================================
3.1 DO NOT put the editor in `rects_layer`.

    `_update_selections_ui` begins by clearing `rects_layer`, `highlight_layer`
    and `selections_list`, and it runs whenever OCR finishes, a page is
    switched, or a region is deleted. An editor living there would be destroyed
    mid-typing, losing the text and the focus.

    Add a SEPARATE `self.inline_editor_layer = ft.Stack(...)` that
    `_update_selections_ui` NEVER clears.

3.2 The new layer must sit ABOVE the gesture detector.

        ft.Stack(controls=[image_control, highlight_layer, rects_layer,
                           gesture_detector])

    `gesture_detector` is on top and swallows pointer events; a TextField under
    it cannot be clicked or typed into. Put the editor layer AFTER it.

    The stack is built in THREE places in custom_gui/app.py. Find them with

        grep -n "ft.Stack(controls=\[self.image_control" custom_gui/app.py

    Update all three, or the editor disappears after a page switch.

3.3 Escape is currently swallowed, and mutation needs the lock.

    In `main()`:

        def on_keyboard(e: ft.KeyboardEvent):
            if viewer.editing_region_id is not None:
                return          # suppress global shortcuts while editing

    Escape must reach your handler while the inline editor is open, while
    Ctrl+N and F2 stay suppressed - typing an "N" must never turn the page.
    Extend that guard; do not remove it.

    Opening and closing the editor mutates `inline_editor_layer.controls`, so it
    must hold `self.selections_lock`, the RLock Task 30c added because flet
    dispatches every non-async handler on a thread pool without serialising
    them. Do not add a second lock.
