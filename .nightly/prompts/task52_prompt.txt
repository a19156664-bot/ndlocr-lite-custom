================================================================================
Task 52: Convert the viewer's CSV export into the delivery spreadsheet
================================================================================

## 1. Purpose and background

A human corrects regions and their text in the viewer, then exports ALL pages
to one CSV (`custom_gui/app.py` `_write_export`, scope "all";
`custom_gui/exporter.py` `rows_to_csv_text`). The customer does not want that
CSV. They want a fixed spreadsheet: ONE ROW PER TWO-PAGE SPREAD, with the
spread's text joined by "｜".

This task writes the converter. It is a pure, deterministic transformation.
It never reads images and never runs OCR.

The customer's template workbook is NOT in this repository and must never be
added to it. The converter receives its path at run time. Your tests must
build their own small template with openpyxl (section 4).

## 2. The input — the viewer's CSV (exists today, do not change it)

UTF-8 with BOM, header row, columns in this order:

    image_name, region_id, x1, y1, x2, y2, line_count, text

    image_name  basename of the page image, e.g. "国際寫眞新聞_141号_p0001.png"
                (older material uses e.g. "国際寫眞新聞_028号_000001.jpg")
    region_id   "mark" for a page-level tag row (text is e.g. "【広告】"),
                otherwise the region number as a string: "1", "2", ...
    text        the region's text; may contain "\n"; may be empty

Rows are grouped by page in page order, and within a page the "mark" row (if
any) comes first, then regions in viewer order. A page with no regions and no
mark has NO rows at all.

**Region "1" on every page is a whole-page frame generated automatically by
the local launcher. The approver decided (2026-10-03) its text must NEVER
reach the delivery.** Every other region_id, and "mark", is delivered.

## 3. The output — the delivery workbook

Sheet name "入力フォーム". Rows 1 and 2 are the template's header and
instructions: copy them through untouched (load the template, write into it,
save under a new name). Data starts on row 3.

### Spread rows for a PDF of N pages (N even, N >= 6)

    row index i (1-based)  A (str)          B (str)                      PDF pages
    1                      "01"             "表紙"                        [1]
    2                      "02"             "表見返し-P.0001"             [2, 3]
    k, 3 <= k <= N/2 - 1   f"{k:02d}"       f"P.{2k-4:04d}-P.{2k-3:04d}"  [2k-2, 2k-1]
    N/2                    f"{N/2:02d}"     f"P.{N-4:04d}-裏見返し"        [N-2, N-1]
    N/2 + 1                f"{N/2+1:02d}"   "裏表紙"                      [N]

    N = 52 -> 27 rows: 表紙, 表見返し-P.0001, P.0002-P.0003, ..., P.0046-P.0047,
              P.0048-裏見返し, 裏表紙
    N = 68 -> 35 rows: ..., P.0062-P.0063, P.0064-裏見返し, 裏表紙
    N odd or N < 6 -> ValueError   (N = 4 would make row 2 both 表見返し and 裏見返し)

Spreadsheet row of spread i is 2 + i. Every spread gets its row with A and B
filled EVEN WHEN IT HAS NO TEXT (the approver uses the rows to check the page
count).

### Column C (キーワード) for one spread

For each PDF page of the spread in ASCENDING page order:
  1. the page's "mark" row text(s), then
  2. its region rows in CSV order, SKIPPING region_id "1".
Turn every text into segments exactly like `exporter.rows_to_txt_text` does:
replace "\r\n" and "\n" with "｜", split on "｜", strip each piece, drop empty
pieces. Concatenate the segments of the whole spread.

Then, within the spread:
  - a TAG is a segment matching ^【[^【】]+】$ . Drop a tag segment when the
    same tag already appeared earlier in this spread (both pages being adverts
    gives "【広告】" once). Never drop or merge non-tag segments.
  - spread 1 (表紙): if "【表紙】" is not among its segments, put it first.

C = "｜".join(segments). If there are no segments, leave C empty (None).

### Columns D, F1

    D (row r) = '=IF(LEN(B{r})+LEN(C{r})<>0,LEN(B{r})+LEN(C{r}),"")'
                (write the formula string; for every data row)

Rows of the template below the last spread row: set A, B and C to None, keep D.
Leave F1, G1 and every other cell of rows 1-2 exactly as in the template.

### Page number from image_name

    regex r"_p?(\d+)\.[A-Za-z0-9]+$"  -> int(group 1)

No match -> ValueError naming the image. Page < 1 or > N -> ValueError.
Two different stems (the part before the matched suffix) in one CSV ->
ValueError (one issue per run).

## 4. Contract — new file `custom_gui/form_export.py`

    def spread_rows(n_pages: int) -> list[tuple[str, str, list[int]]]:
        """[(A, B, pdf_pages), ...] as in section 3."""
