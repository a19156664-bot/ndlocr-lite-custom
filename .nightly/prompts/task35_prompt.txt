4. DELIVERABLES
================================================================================
[A] A new pure module: custom_gui/save_paths.py

    No flet import, no I/O, no GUI. Pure string functions so they can be
    tested honestly.

        def resolve_export_dir(image_path, pdf_source=None) -> str
            If pdf_source is not None, return the directory of pdf_source.
            Otherwise return the directory of image_path.
            Always an absolute path.

        def export_basename(image_path, scope, export_dir) -> str
            scope == "current" -> the image file's stem
                                  ("a/b/foo_0008.jpg" -> "foo_0008")
            scope == "all"     -> "<the last path component of export_dir>_all"
                                  ("C:/scan/国際寫眞新聞_028号" ->
                                   "国際寫眞新聞_028号_all")
            If export_dir has no usable last component (a drive root such as
            "C:\\" or "/"), use "export_all" for scope "all".

        def export_targets(image_path, scope, pdf_source=None) -> (csv, txt)
            The two absolute paths: <dir>/<basename>.csv and
            <dir>/<basename>.txt.

    WHY pdf_source: a PDF page is rendered into tempfile.mkdtemp(), which is
    deleted when the app exits. Writing the export next to it would silently
    throw the user's work away. For a PDF page the export goes next to the
    SOURCE PDF.

[B] A new pure module: custom_gui/region_stats.py

        def count_line_breaks(text) -> int

    Normalise "\r\n" to "\n", drop trailing newlines, then count "\n".

        ""            -> 0
        "abc"         -> 0
        "a\nb"        -> 1
        "a\r\nb"      -> 1        (\r\n is ONE break, not two)
        "a\nb\n"      -> 1        (a trailing break is not counted)
        "a\nb\r\n"    -> 1
        "a\n\nb"      -> 2
        None          -> 0

[D] Saving no longer opens a file dialog

    `_start_export(scope)` keeps its existing validation and its existing
    status messages EXACTLY as they are:

        "Nothing to export"
        "OCR not finished - cannot export yet"
        "Nothing to export (N skipped: OCR not finished)"

    After validation it must NOT call `self.file_picker.save_file`. Instead:

        1. Work out the pdf_source for the current image: if `self.image_src`
           is a key of `self.pdf_page_map`, the source PDF is the first
           element of the tuple stored there; otherwise None.
        2. csv_path, txt_path = export_targets(self.image_src, scope, pdf_source)
        3. If EITHER file already exists, open the overwrite dialog [E].
           Otherwise write immediately and open the done dialog [F].

    The writing itself moves into its own method so it can be tested and so
    both the direct path and the overwrite path use ONE implementation:

        def _write_export(self, scope, csv_path, txt_path) -> str

    It builds the rows exactly as the code does today (build_export_rows with
    edited_texts=self.edits for "current", build_export_rows_multi over
    _collect_all_export_pages() for "all"), writes the CSV as utf-8-sig with
    newline="" and the TXT as utf-8, and returns the success message. Do not
    change the export FORMAT, the encodings, or the messages' wording beyond
    the file names they now mention.

    Delete the save branch from `_on_file_picker_result`. The "folder" and
    "pdf" branches stay untouched, and `self.file_picker` stays registered.

[E] The overwrite dialog - two buttons
