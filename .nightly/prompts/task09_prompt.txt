2. THE FATAL DEFECT THAT CAUSED THE REJECTION
--------------------------------------------------------------------------------
In integration/task-08, custom_gui/app.py uses `page.window_width` and
`page.window_height`:

        win_w=page.window_width or 800,
        win_h=page.window_height or 600,
        ...
        viewer.update_layout(page.window_width or 800, page.window_height or 600)

These attributes DO NOT EXIST in flet 0.27.6, which is the pinned version of this
project. This was verified directly:

        hasattr(ft.Page, 'window_width')  -> False
        hasattr(ft.Page, 'window_height') -> False
        hasattr(ft.Page, 'width')         -> True
        hasattr(ft.Page, 'window')        -> True

Because of this, the application raises AttributeError as soon as main() runs.
The unit tests all passed (28 passed) because no test starts the GUI. This is
exactly the same class of defect as a previous rejection in this project, where
`ft.colors.transparent` was used and did not exist.
