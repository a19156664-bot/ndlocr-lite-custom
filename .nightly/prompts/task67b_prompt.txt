## 1. Purpose and background

During the human check, the approver marks frames the OCR could not read by
typing "■■NG■■" into them, then has to tell the commander which page and which
region each one is, so the commander can re-read them while the approver
keeps working. Today the approver reads the page from the status bar and the
region from the list header by eye. The approver asked (2026-10-10) for a
button that gets the page and the region number at once.

Design (decided by the commander, who is the reader of the copied text):

  - In the right-hand list, each region row gets one more icon button
    (ft.Icons.CONTENT_COPY, tooltip "頁と枠番号をコピー"), placed just
    before the Delete button (after "Revert to OCR" when that is shown).
  - Clicking it copies "<image name without extension> <region label>" to the
    clipboard, e.g. "国際寫眞新聞_143号_p0014 Region 3", and shows
    "コピーしました: 国際寫眞新聞_143号_p0014 Region 3" in the status bar
    (self.latest_region_info), so the text can be read even where the
    clipboard does not work.
  - It changes nothing else: no edits, no order, no selection, no saving.
  - Unknown region id: do nothing. No page attached: no clipboard call, but
    the status text is still set.
