Task 05: [NEW] 範囲フィルタ（boundingBox による行の絞り込み）

本リポジトリのルートにある AGENTS.md（プロジェクト憲法）を必ず読み、その規約に従って作業すること。

1. 目的・背景 (Purpose & Background):
本プロジェクトは NDLOCR-Lite を fork し、「マウスで矩形範囲を選択して、その範囲だけOCR結果を取り出す」
機能を追加するものである。上流コードは一切変更せず custom_gui/ にのみ実装する（C方式）。

本タスクは**本プロジェクトの中核ロジック**である。
ページ全体のOCR結果（行のリスト）と、ユーザーが選択した矩形を受け取り、
「その矩形の中にある行だけ」を返す判定処理を実装する。

2. 既存コードの契約（master に実装済み。変更禁止）:
`custom_gui/ocr_bridge.py` の `run_ocr_and_parse(image_path: str)` は、
以下の構造の dict を要素とする list を返す。本タスクはこの構造を入力として扱うこと。

    {
        "text":         str,                      # 認識テキスト
        "bbox":         (x1, y1, x2, y2),         # 原画像座標の float タプル。x1 < x2, y1 < y2
        "confidence":   float,                    # 信頼度
        "is_vertical":  bool,                     # 縦書きなら True
        "source_image": str                       # 元画像のファイル名
    }

3. 完了条件 (Definition of Done):
   - `custom_gui/region_filter.py` を新規作成し、以下の純粋関数を実装すること:
       - 選択矩形 (x1, y1, x2, y2) と 上記構造の行リストを受け取り、
         矩形内と判定された行のみを**元の順序を保ったまま**返す関数
   - 判定方式は「**重なり面積が行の面積の50%以上**」とすること。
     この閾値は定数として定義し、引数で変更可能にすること（デフォルト0.5）。
     採用理由をコード内コメントに明記すること。
   - **退化した bbox（幅0または高さ0、すなわち面積0）の扱いを明示的に実装すること。**
     面積0の行は 0除算を起こすため、「矩形に完全に内包される場合のみ含める」ルールとし、
     この判定をコード内コメントで説明すること。
     **面積0の行を強制的に面積1に水増しするなどのデータ改変を行ってはならない。**
   - `tests/test_region_filter.py` を新規作成し、`python -m pytest tests/ -v` が全件グリーンになること。
     テストには以下を**具体的な数値**で含めること:
       (a) 完全内包: 選択矩形(0,0,100,100)、行bbox(10,10,50,50) → 含まれる
       (b) 完全に外側: 選択矩形(0,0,100,100)、行bbox(200,200,250,250) → 含まれない
       (c) 部分重なり・50%以上: 選択矩形(0,0,100,100)、行bbox(50,50,150,60)
           （行の面積 100x10=1000、重なり 50x10=500 → 50%ちょうど）→ 含まれる
       (d) 部分重なり・50%未満: 選択矩形(0,0,100,100)、行bbox(80,50,180,60)
           （行の面積 100x10=1000、重なり 20x10=200 → 20%）→ 含まれない
       (e) 境界接触のみ: 選択矩形(0,0,100,100)、行bbox(100,100,150,150)
           （重なり面積0）→ 含まれない
       (f) 退化bbox: 選択矩形(0,0,100,100)、行bbox(10,10,10,50)（幅0）→ 内包されるので含まれる
       (g) 順序保持: 5行を入力し、うち3行が該当する場合、
           戻り値の3行が入力時の順序と同じであること
       (h) 該当0件の場合に空リストが返ること（None やエラーではないこと）

8. 技術的ヒント:
   - テストは OCR を実行しないこと。行データは**テスト内で手書きした固定の dict**を使うこと
     （実OCRを走らせるとテストが数十秒かかるため）。
   - 2つの軸平行矩形の重なり面積は
     `max(0, min(x2a,x2b) - max(x1a,x1b)) * max(0, min(y2a,y2b) - max(y1a,y1b))` で求まる。
