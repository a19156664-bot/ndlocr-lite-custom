================================================================================
2. THE CAUSE - VERIFIED, DO NOT RE-INVESTIGATE
================================================================================
`ft.MouseCursor.GRAB` is the Flutter cursor kind string "grab", which maps to
`SystemMouseCursors.grab`. That cursor is NOT IMPLEMENTED in the Flutter
Windows embedder: the Windows `GetCursorByName` mapping has no IDC_ constant
for "grab", "grabbing" or "verticalText", so Flutter silently falls back to
the default arrow.

    flutter/flutter issue #99323
    "[Windows] SystemMouseCursors grab, grabbing and verticalText aren't
     working on Desktop"  - P2, still OPEN as of July 2026.
    "windows and windows uwp entries missing in flutter docs";
    with SystemMouseCursors.grab on Windows the "basic cursor symbol is shown".
    Works correctly on web, macOS, Android and Linux.

Windows has no open-hand or closed-fist cursor at all. The only hand in Win32
is IDC_HAND, the pointing hand, reached through the "click" kind.

The commander enumerated all 36 members of `ft.MouseCursor` in this project's
own venv. The values that matter here:

    ft.MouseCursor.CLICK       'click'       -> IDC_HAND     pointing hand
    ft.MouseCursor.ALL_SCROLL  'allScroll'   -> IDC_SIZEALL  four-way arrow
    ft.MouseCursor.MOVE        'move'        -> IDC_SIZEALL  four-way arrow
    ft.MouseCursor.PRECISE     'precise'     -> IDC_CROSS    crosshair (works today)
    ft.MouseCursor.GRAB        'grab'        -> NOT MAPPED   falls back to arrow
    ft.MouseCursor.GRABBING    'grabbing'    -> NOT MAPPED   falls back to arrow
