================================================================================
Task 66: Page jump in the confirmation viewer -- type a page number and press
         Enter (or the "移動" button) to go straight to that page
================================================================================

This order is Task 66 of the commander's local ROADMAP (not on GitHub; you
do not need it: everything is in this order).

## 1. Purpose and background

Today the confirmation viewer moves between pages only one at a time
(Previous / Next buttons and Ctrl+N). Issues have 52 to 68 pages, and the
approver works from lists that name a page number ("p51 frame 8"). The approver
asked (2026-10-10) for a way to jump to a page, and chose this design ("案甲"):

  - Right after the Next button: a small text field (hint "頁") and a
    "移動" text button. Typing a number and pressing Enter, or clicking
    "移動", goes to that page.
  - Page numbers start at 1 and equal the PDF page number (the viewer lists
    every PDF page in order; the status bar already shows [index+1/count]).
    Full-width digits typed with a Japanese IME ("１２") are accepted.
  - Empty, not a number, or outside 1..count: do NOT move. Show
    "頁は 1〜N の数で入れてください（入力: ...）" in self.latest_region_info
    and keep the typed text so it can be corrected.
  - Same page as now: do not reload it.
  - Moving goes through the same self._switch_image(...) as Previous / Next,
    so saving the current page and restoring the target page work the same.

+def page_index_from_text(text: Optional[str], count: int) -> Optional[int]:
+    """
+    Task 66: 頁番号の入力（1 始まり。全角の数字も可）を 0 始まりの位置にする。
+    空・数でない・1〜count の外は None（移らない）。
+    """
+    s = (text or "").strip()
+    if not s or not s.isdecimal():
+        return None
+    n = int(s)
+    if 1 <= n <= count:
+        return n - 1
+    return None
