3. DEFINITION OF DONE
--------------------------------------------------------------------------------
[A] The user can choose the scope of the export.
    - Pressing Export offers two choices:
          "Current image only"   - exactly today's behaviour, unchanged
          "All images"           - every image that has rectangles
    - Use whatever obvious control you prefer: an ft.AlertDialog with two
      buttons, or a second toolbar button, or a dropdown next to Export. It must
      be visible and self-explanatory in the UI.
    - A user who wants today's behaviour must still be able to get it. Do not
      silently repurpose the existing button.

[B] "All images" collects from self.image_states.
    - Build the `pages` list in SEQUENCE ORDER, i.e. the order of
      `self.sequence`, not Python dict order, so the output follows page order.
    - For each image pass its own rects (`selections.get_all()`), its own
      `ocr_results` and its own `edits`.
    - Use `build_export_rows_multi`. Do not reimplement the aggregation.
    - Write BOTH files from the single chosen path, exactly as the current-image
      export does: `result.csv` plus `result.txt`.

[C] Guard rails - none of these may crash.
    - No image has any rectangle: status bar says "Nothing to export" and NOTHING
      is written.
    - Images whose `ocr_state` is not DONE are EXCLUDED from the output, and the
      status bar reports how many were skipped, for example:
          "Exported 7 regions from 3 images (2 skipped: OCR not finished)"
      Do NOT wait for OCR and do NOT start OCR for images the user never opened.
    - On success with nothing skipped, the message states regions AND images,
      for example "Exported 7 regions from 3 images".
    - Dialog cancelled: do nothing, no error.
    - Write failure: catch it, show the reason in the status bar, do not crash.

[D] Encoding is unchanged and still mandatory.
    CSV with encoding="utf-8-sig" (UTF-8 WITH BOM, so Japanese Excel does not
    produce mojibake), TXT with encoding="utf-8", CSV opened with newline="" and
    written with the standard library `csv` module.

[E] Tests - `tests/test_export_scope.py` (new file), no GUI, no real OCR.
    Put the page-collection logic in a testable method or helper so it can be
    called without clicking. Concrete assertions:
      (a) Three images in sequence order a.jpg / b.jpg / c.jpg with 2 / 0 / 1
          rectangles, all with ocr_state DONE: the collected `pages` yields rows
          whose image_name values are exactly ["a.jpg", "a.jpg", "c.jpg"].
      (b) The same three images but b.jpg has 2 rectangles and ocr_state RUNNING:
          b.jpg contributes NO rows, and your skipped counter equals exactly 1.
      (c) An edit registered for a.jpg rect "1" appears in that row, and the
          c.jpg rect "1" row is unaffected - assert both exact strings.
      (d) No image has any rectangle: the collected pages produce ZERO rows.
      (e) Sequence order is respected: build the image_states dict in a
          DIFFERENT insertion order from the sequence, and assert the rows still
          come out in sequence order. This is the regression guard for [B].

[F] Regression safety.
    - `python -m pytest tests/ -v` must pass completely (66+ tests).
    - Do NOT modify custom_gui/exporter.py. Its logic is finished and tested.
    - Do NOT modify custom_gui/ocr_bridge.py, custom_gui/region_filter.py,
      custom_gui/selection.py, custom_gui/text_assembler.py,
      custom_gui/image_sequence.py, custom_gui/viewer.py.
    - Do NOT modify ANY existing file under tests/. In particular
      tests/test_flet_constants.py is a guard test: if it objects to your code,
      CHANGE YOUR CODE. Never add an exemption to it. Note that a local variable
      named `page` will collide with it - name yours something else.
    - Everything a human has verified must keep working: rectangle selection,
      the Select/Pan toggle, panning, yellow highlights, the "Region N" label
      drawn OUTSIDE the rectangle, async OCR with its progress ring, the
      current-image CSV/TXT export, folder loading, Prev/Next/Ctrl+N, and the
      F2 / EDIT text correction with its revert button.
    - Guard every `.update()` call on a control with `if self.page:`.
    - NEVER use `self.image` or `self.scale` as attribute names.
    - Do not run real OCR in your tests.
    - Leave NO scratch or probe files anywhere in the repository. Check
      `git status` before you finish. A previous task left three at the
      repository root and the commander had to delete them.
