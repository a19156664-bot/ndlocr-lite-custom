================================================================================
2. WHY
================================================================================
On the error path `_switch_image` does

        self.image_container.content = ft.Text(self.ocr_error, ...)

which removes `self.stack` from the control tree. EVERYTHING inside the stack
goes with it:

        self.image_control        (Task 28 guarded this one)
        self.highlight_layer      <- still unguarded, crashes
        self.rects_layer          <- still unguarded, crashes next
        self.gesture_detector

But `_update_selections_ui` guards on the PARENT:

        if self.page:                     # the VIEWER has a page, so this passes
            self.highlight_layer.update()  # the LAYER does not -> assert
            self.rects_layer.update()
            self.selections_list.update()  # this one IS still attached - fine

`self.page` being set proves nothing about a child that was just detached.
`self.selections_list` lives in the right-hand panel, not in the stack, so it is
still attached and must keep updating normally.

Note that `_update_viewer` already skips the SIZING of those layers when
ocr_error is set. The sizing was guarded; the updating was not.
