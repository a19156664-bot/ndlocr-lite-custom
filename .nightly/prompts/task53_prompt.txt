================================================================================
Task 53: A per-region "この枠だけOCR" button (OCR the region's crop on demand)
================================================================================

## 1. Purpose and background

The viewer shows, for every region, the text of the page-wide OCR lines that
fall inside it (`filter_lines_by_region`, 50 % of a line's area). The commander
measured five magazine issues on 2026-10-03: of 690 hand-marked regions, 111
receive NO line at all. In many of them the page-wide OCR failed (decorative
titles, captions inside drawings were merged into one huge garbage line such
as "000000…"). Cropping just the region and running the same OCR on the crop
reads several of them correctly, for example:

    p36 crop -> "先生が轉んだので……"     p36 crop -> "北正夫"
    p33 crop -> "(文責在記者)-"

But on crops of photographs the OCR invents text with HIGH confidence
("これにしている。" at 0.875 on a crop that is only photo texture). So this
must NEVER run automatically. The approver decided (2026-10-03): a button per
region; the human presses it; the result becomes that region's edited text,
which the human then checks, corrects or reverts.

## 2. Contract

### DoD-1 — new file `custom_gui/region_ocr.py`

    REGION_OCR_PAD = 16          # pixels added on every side before OCR

    def crop_region(image_bgr, bbox, pad: int = REGION_OCR_PAD):
        """Return image_bgr[y1-pad:y2+pad, x1-pad:x2+pad], clipped to the image.
        bbox is (x1, y1, x2, y2) in original pixels; floats are allowed
        (round down x1/y1, round up x2/y2)."""

    def region_ocr_text(image_path: str, bbox, pad: int = REGION_OCR_PAD) -> str:
        """Crop the region from the image file, write the crop as PNG into a
        temporary directory, OCR it, and return the line texts joined with
        "\n" in the order the OCR returned them. "" when no line has text.
        The temporary directory is removed before returning, also on error.
        Exceptions from the OCR propagate unchanged."""

Rules:
- Read the image with `custom_gui.mark_detector.load_image` and write the
  crop with `cv2.imencode(".png", crop)[1].tofile(path)`. Do NOT use
  cv2.imread / cv2.imwrite: they silently fail on Japanese paths, and the
  real files are named like 国際寫眞新聞_141号_p0036.png.
- Call the OCR as `ocr_bridge.run_ocr_and_parse(png_path)` through the MODULE
  (`from custom_gui import ocr_bridge`), looked up at CALL time. Do NOT do
  `from custom_gui.ocr_bridge import run_ocr_and_parse`. Tests replace
  `custom_gui.ocr_bridge.run_ocr_and_parse` and that replacement must reach
  this call.
- Ignore lines whose "text" is empty or whitespace.

### DoD-2 — `custom_gui/app.py`, only inside `_update_selections_ui`'s per-region row, plus one new method

In the per-region row (around lines 1464-1470) the buttons are built as:

    buttons = [
        ft.IconButton(icon=ft.Icons.EDIT, tooltip="Edit", on_click=edit_rect),
        ft.IconButton(icon=ft.Icons.SWAP_HORIZ, tooltip="右から変換", on_click=rtl_rect)
    ]

Append, right after the "右から変換" button and before RESTORE / DELETE:

    ft.IconButton(icon=ft.Icons.DOCUMENT_SCANNER, tooltip="この枠だけOCR",
                  on_click=lambda e, rid=rect.rect_id: self.start_region_ocr(rid))

Add the method `start_region_ocr(self, rid)` to `SelectableImageViewer`:

    1. If rid already has an entry in self.edits: do NOT run OCR. Set
       self.latest_region_info = "編集済みの枠は範囲OCRしません（元に戻してから押してください）",
       call self._update_status(), return.
    2. Find the rect by rid in self.selection_container; if missing, return.
    3. Set self.latest_region_info = "範囲OCR中…", call self._update_status().
    4. Run the work with self.page.run_thread(target) (OCR takes ~5 s):
         text = region_ocr_text(self.image_src, rect.bbox)
       - on exception: latest_region_info = f"範囲OCR失敗: {e}" ; no edit
       - text == "": latest_region_info = "範囲OCR: 文字が見つかりません" ; no edit
       - otherwise, under `with self.selections_lock:` and ONLY IF the rect with
         that rid still exists AND self.image_src is still the same image as when
         the button was pressed: self.edits[rid] = text ;
         latest_region_info = f"範囲OCR: {n} 行" (n = number of lines in text)
       then call self._update_selections_ui(), self._persist_work_state(),
       self._update_status() (only the first and last when there was no edit).

Nothing else in app.py changes. Do not touch commit_edit, rtl_rect,
restore_rect, the label text, the export, or any other method.
