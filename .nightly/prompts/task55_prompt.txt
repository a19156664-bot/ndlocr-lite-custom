================================================================================
Task 55: Show / hide one region's box on the image (an eye button per row)
================================================================================

## 1. Purpose and background

The approver checked issue 141 page 5 in the viewer on 2026-10-06. Region 4
(a heading) was found by the mark reader. Region 8 had been missed, so the
approver drew it by hand. Region 8 sits just above-left of Region 4, and the
blue "Region 4" label (drawn above the top-left corner of every box, 70 %
opaque blue, app.py _redraw_overlays) and Region 4's yellow line highlights
lie on top of Region 8's text. The approver cannot proof-read Region 8.

The approver decided (2026-10-06):

  - Each row of the right panel gets one eye button. Pressing it hides THAT
    region's blue border, its label and its yellow line highlights on the
    image. Pressing it again shows them again.
  - Hiding is DISPLAY ONLY. The region still exists: its row stays in the
    right panel with its text, it is still saved, and it is still exported
    (Excel / CSV) exactly as today.
  - The hidden state is NOT saved. It is remembered per page while the viewer
    runs (go to another page and come back: still hidden). A new viewer
    (restart) starts with everything shown.

## 2. Contract

### DoD-1 -- per-page hidden set (app.py, SelectableImageViewer)

1. In __init__, right after `self.image_states = {}`, add
       self.hidden_regions = {}      # image path -> set of rect_id (str)
   Do NOT add a key to the image_states dicts: a launcher outside this
   repository builds image_states entries itself with exactly the six keys
   selections / ocr_state / ocr_results / ocr_error / edits / mark.
2. Add a method
       def _hidden_ids(self):
           return self.hidden_regions.setdefault(self.image_src, set())
   The key is the current page's image path (self.image_src).
3. The hidden set is never written to disk. _persist_work_state,
   _load_persisted_state, custom_gui/work_state.py and the export are NOT
   changed.

### DoD-2 -- the image side skips hidden regions (app.py, _redraw_overlays)

At the top of the `for rect in all_rects:` loop in _redraw_overlays:
if str(rect.rect_id) is in self._hidden_ids(), `continue` (no border, no
label, no highlight for that rect). Everything else in _redraw_overlays stays
exactly as it is (including the Region 1 / lime rule from Task 54).
Because zoom (_update_viewer), page switch and every rebuild go through
_redraw_overlays, a hidden region stays hidden through all of them.

### DoD-3 -- the eye button (app.py, _update_selections_ui, right panel)

1. In the `buttons = [...]` list of each row, insert ONE IconButton right
   after the "この枠だけOCR" button and before the optional RESTORE button and
   the DELETE button. So the order is:
       Edit, 右から変換, この枠だけOCR, <eye>, [Revert to OCR], Delete
2. When the rect is shown:  icon=ft.Icons.VISIBILITY,
                            tooltip="画像の枠を隠す"
   When the rect is hidden: icon=ft.Icons.VISIBILITY_OFF,
                            tooltip="画像の枠を表示"
3. on_click calls a new method
       def toggle_region_visible(self, rid, button=None):
   which does, all inside ONE `with self.selections_lock:` block:
     - add rid to self._hidden_ids() if absent, remove it if present
     - self._redraw_overlays()
     - update self.highlight_layer and self.rects_layer the way
       _update_selections_ui does (only when they have a page)
     - if button is not None: set button.icon and button.tooltip to the new
       state (DoD-3.2) and call button.update() if button.page
   It must NOT call _update_selections_ui (that rebuilds the right panel and
   would destroy a TextField the user is typing in another row), and must NOT
   call _persist_work_state.
   The on_click lambda passes the clicked button: e.g.
       on_click=lambda e, rid=rect.rect_id: self.toggle_region_visible(rid, e.control)
4. Do NOT change the tree shape of the row. Existing tests read
   row.content.controls[0] as an ft.Row with exactly 2 controls
   [header ft.Text, ft.Row(buttons)] (wrap=True from Task 54). The new button
   goes INSIDE the buttons Row. The ListView width stays 300.

### DoD-4 -- a hidden region cannot be tapped on the image (app.py, _on_tap_up)

In _on_tap_up, pass find_region_at_point only the rects that are NOT in
self._hidden_ids() (instead of self.selection_container.get_all()). Nothing
else in _on_tap_up changes. Reason: the approver hides Region 4 to work on
Region 8 underneath; a tap there must not open the invisible Region 4.

Nothing else in app.py changes. Do not touch delete_rect, rtl_rect,
restore_rect, start_region_ocr, commit_edit, _update_viewer, the inline
editor, the export, the label text format, or custom_gui/selection.py.
