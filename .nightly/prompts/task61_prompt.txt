This order is Task 61 in .nightly/ROADMAP.md (AGENTS.md section 8.13).

## 1. Purpose and background

Task 60 (on master) added custom_gui/vertical_ocr.py with

    vertical_ocr_text(image_path, bbox, pad=REGION_OCR_PAD, recognizer=None) -> str

which reads a frame as vertical text without line detection. The approver
wants it as a button in each row of the right panel, next to the existing
buttons.

On master, custom_gui/app.py, SelectableImageViewer:
  - _build_row(self, rect) builds `buttons = [Edit, 右から変換, この枠だけOCR,
    eye (画像の枠を隠す / 画像の枠を表示)]`, then appends "Revert to OCR"
    (only when edited) and "Delete".
  - The "この枠だけOCR" button calls self.start_region_ocr(rid).
  - start_region_ocr(self, rid) refuses an edited row, colours the row
    ORANGE_100, and runs _run_region_ocr in a thread, which calls
    `text = region_ocr_text(saved_image_src, rect.bbox)` and then applies the
    text to ONLY that row (_refresh_row), protects a row being edited, and
    clears the colour in `finally` (AGENTS.md 8.12, Task 59b).

The new button must use EXACTLY that flow; only the reading function differs.
