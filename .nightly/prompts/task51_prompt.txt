================================================================================
Task 51: Let "マーク読取" use a yellow-green (lime) marker instead of cyan
================================================================================

## 1. Purpose and background

`custom_gui/mark_detector.detect_marks()` finds hand-drawn highlighter marks
by colour. It only knows CYAN today:

    CYAN_LOWER = (80, 120, 180)      # OpenCV HSV, H is 0-179
    CYAN_UPPER = (105, 255, 255)

The approver now works on a new set of five magazine issues (276 pages). In
those, the hand-drawn marker is YELLOW-GREEN, not cyan. The commander measured
all 276 pages on 2026-10-03:

    lime marker pixels sit at H = 40-50 (OpenCV), on 40 of 52 pages of one issue
    cyan bounds find ZERO hand marks there; they only hit blue PRINTED ink
        (adverts and one cover), 128 false regions over the five issues
    the orange "advert" detector (detect_page_mark) only hits the red PRINTED
        masthead on each cover; there is no hand-drawn orange in these issues

The approver decided (2026-10-03): for this material, ONLY lime is a range
mark; cyan and orange must not be detected. The OLD material (cyan + orange)
must keep working exactly as today. So the colour becomes a setting, and the
default stays cyan.

The setting is chosen by an environment variable, set by the local launcher
(not in this repository). You do not write the launcher.

Add, next to the existing constants:

    LIME_UPPER = (75, 255, 255)

Change the signature of `detect_marks` by appending ONE keyword argument with a
