2. ROOT CAUSE - ALREADY DIAGNOSED. DO NOT RE-INVESTIGATE.
--------------------------------------------------------------------------------
`tests/test_async_ocr.py::test_viewer_init_does_not_run_ocr` constructs the
viewer with a NON-EXISTENT file:

        viewer = SelectableImageViewer(
            image_src="dummy.jpg",
            img_w=100, img_h=100,
            win_w=100, win_h=100
        )

The defective code is guarded by `if os.path.exists(image_src):`. Because
"dummy.jpg" does not exist, that branch is never entered, the monkeypatched OCR
function is never called, and `ocr_called` stays False. The assertion passes
regardless of whether the defect is present.

Every other test in the file constructs the viewer the same way, so several of
them are exercising the `OcrState.ERROR` path rather than the normal path they
appear to be testing.
