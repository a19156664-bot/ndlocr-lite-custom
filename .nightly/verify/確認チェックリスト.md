## 起動（PowerShell に貼る）

**貼る場所**：Windows の検索窓に `PowerShell` と打ち、出てきた「Windows PowerShell」を開く。

```powershell
cd C:\Users\user\ndlocr-lite-custom
.\.venv\Scripts\python.exe -m custom_gui.app
```

**何が起きるか**：10〜20秒ほど黒い画面のまま無反応になる（正常）。その後アプリの窓が開く。
`cd` を省かないこと。相対パスで初期画像を開くため、リポジトリ直下からでないと画像が出ない。
`Activate.ps1` は使わない（この端末は実行ポリシーが Restricted）。

| 出た文字列 | 意味・原因 | 次の対処 |
|---|---|---|
| `用語 '.\.venv\Scripts\python.exe' は認識されません` | `cd` していない | 1行目からやり直す |
| `No module named custom_gui` | 同上（別の場所から起動した） | 1行目からやり直す |
| `Output Directory is not found.` | OCR の出力先が無い | `mkdir jpg\_ocr結果` を先に打つ |
| 窓が開かず、赤い文字が大量に出る | 実装の不具合 | **その赤い文字をそのまま指揮官へお送りください** |

## 空14件の原因を、先に機械で測った（2026-09-02 15:44）

**範囲**：`jpg/` の52枚のみ／2026-08-28 の OCR 結果1回分／マーク118範囲・空14件を全数。
**測り方**：`detect_marks` の矩形と `parse_ocr_json` の行 bbox の重なりを、
`filter_lines_by_region` と同じ式（**行の面積に対する重なりの割合**・閾値 0.5）で計算した。

人が判断すべきだった「①OCR が読めていない ②枠がずれている」は、**14件中10件が②だった。**

| 原因 | 件数 | 中身 |
|---|---|---|
| ② 枠が行の半分を覆えていない | **10** | OCR は文字を読めている。割合が 0.5 に届かず落ちた |
| ① その場所に OCR の行が1本も無い | **4** | 写真・図版の疑い。人が見ないと分からない |

**①の4件（ここだけは人の目が要る）**

|---|---|---|---|
| 000044 | 1 | box | 203×465 |

| 000013 | 3 | line | 59×27 |
| 000021 | 3 | box | 55×21 |

### p000008 の `Region 3`（抽出の範囲2）— 前回「幅44px が細すぎる」と書いた件

**細いことは原因ではなかった。** 枠 x=917〜961 が、**隣り合う2本の列の谷間**に載っていた。

* 左の列 x=897〜936（w=39）「押し切るか?」→ 割合 **0.482**
* 右の列 x=948〜989（w=41）「挂冠するか?」→ 割合 **0.292**

どちらも 0.5 に届かず、両方が落ちて 0行になった。
**OCR はこの2行を正しく読んでいる。**

**閾値 0.5 は `custom_gui/region_filter.py:16` に理由が書かれた意図的な値である。**
下げる／枠を広げる／どちらもしない、は承認者のご判断を仰ぐ（欠陥とは呼ばない）。
